# Configuration catalog

analysis_config.yaml is a provenance catalog of recorded settings and frozen output properties. It is not a unified runtime configuration: most retained scripts do not read it. No script default was changed to match a frozen result.

The WGCNA powers 12/16 are observed automatic-selection outputs, not historical fixed CLI flags. Dynamic target-per-module and exact CLI remain unknown. Code defaults are documented separately from formal run facts. Final random-set/Stouffer inference uses only method_revision_v2 with B=10,000.
